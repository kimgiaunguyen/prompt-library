# AI Prompt Library — reusable templates for everyday operations

Personal demo project by Kim Giau Nguyen.

Five ready-to-use prompt templates, organized like a small internal knowledge base:
supplier quotation comparison, tender and spec key points, follow-up email,
meeting summary and actions, and SOP draft from rough notes.

Each template has input fields, a generated prompt to copy into ChatGPT or Claude,
and a "verify before use" checklist. Every prompt tells the AI to use only the
text provided, to flag gaps instead of guessing, and to leave decisions with the team.

All example inputs and outputs are fictional.
