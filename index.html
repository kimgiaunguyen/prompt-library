An AI prompt library for everyday operations work

Five reusable templates for common office tasks. Fill in the fields, copy the prompt into ChatGPT or Claude, then run the checklist before using the result. Every template is built to stop the AI from guessing and to leave decisions with the team.

Data privacy. Use only AI tools approved through the company's governance process. Before pasting any text, mask personal data, customer details and confidential business information, following the company's data privacy rules. If you are unsure whether something can be shared, check with the data owner or IT before using the tool.

    Same three quotes, two different prompts
    
    
    Three fictional supplier quotes for 120 LED ceiling panels. The first prompt is how most people ask. The second uses the Supplier quotation comparison template. The outputs below are illustrative examples of the typical result of each prompt.
    
    
    
      
    Supplier ALED panel 600×600, 40W. 120 × 385,000 = 46,200,000 VND, VAT 8% included. Free delivery in HCMC. Lead time 10 days. Warranty 2 years. 30% deposit, 70% on delivery. Valid 15 days.
    
      
    Supplier BLED panel 600×600, 36W. 120 × 350,000 = 42,000,000 VND, excluding VAT. Delivery 1,500,000 VND. Lead time 14 days. Warranty 1 year. 50% deposit. Valid 30 days.
    
      
    Supplier CLED panel 600×600, 40W. 120 × 372,000 = 44,640,000 VND, VAT included. Lead time 7 days. 100% payment on delivery.

    How the library works
    
    
    The library is run like a small internal knowledge base: every template has the same structure, an owner and a review date, so staff can trust it and it stays current.
    
    
    
      
    1. PickChoose the template that matches the task.
    
      
    2. FillComplete the input fields. Paste source text as-is.
    
      
    3. RunCopy the prompt into ChatGPT or Claude.
    
      
    4. VerifyTick the checklist before the result is used.
    
    
    
    
    
      
    Same structure for every template
    Purpose, when to use it, input fields, the prompt, a verify checklist and an example. Staff learn one pattern and can use any template.
    
      
    Built-in guardrails
    Every prompt tells the AI to use only the text provided, to mark gaps instead of guessing, and to cite sources where it extracts facts. Decisions stay with people.
    
      
    Owner, version, review date
    Each template has a named owner and a quarterly review date. When staff report a problem, the owner updates the template and the version number.
    
      
    Measuring impact
    In a real rollout: time per task and rework rate before and after, how often each template is used, and issues caught by the checklist.
    
      
    Data safety
    Remove personal data, prices under NDA and client names before pasting into a public AI tool, unless the company has approved an enterprise AI tool.
    
      
    Adding a new template
    When the same request comes up three or more times, it becomes a candidate. Draft it, test it on two real examples, add a checklist, then publish as version 1.0.
